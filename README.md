# Энергоклассы Татарстана

Презентация сети энергоклассов: вращающийся глобус, карта Татарстана и анимированное подключение лицея «Прогресс».

## Запуск

Сборка и установка зависимостей не нужны. Из корня проекта выполните:

```sh
python -m http.server 8000
```

Откройте http://localhost:8000. Нужен HTTP-сервер: браузер ограничивает загрузку модулей и геоданных через `file://`.

## Структура

- `script.js` — состояние презентации, отсчёт и управление.
- `js/map.js` — карта, маркеры, линии и адаптация к размеру окна.
- `js/globe.js` — глобус и переход к карте.
- `js/audio.js` — загрузка звуков и переключение громкости.
- `js/stars.js`, `js/effects.js` — фон и эффекты подключения.
- `js/config.js` — города, координаты и интервалы отсчёта.
- `js/svg.js` — SVG-элементы и геометрия соединений.
- `style.css` — оформление; основные цвета заданы переменными в `:root`.

Enter, пробел, стрелка вправо и PageDown запускают следующий доступный этап. Кнопка звука находится под логотипом. Уже на начальном экране запускается зацикленная музыка `snd-bg.mp3`: под эффекты она приглушается, в паузах плавно возвращается. Выключение звука ставит фон на паузу, повторное включение возобновляет музыку.

Карта подбирает масштаб по границам Татарстана с учётом панелей интерфейса, включая экран 1920×1200. Изменение размера окна сохраняет маркеры, подключение и эффекты.

Геоданные и библиотеки хранятся локально; спутниковые тайлы загружаются из ArcGIS и требуют интернета. Если браузер блокирует автоматический звук, музыка включается после первого клика в любом месте страницы или нажатия клавиши, ещё до приближения.

## Публикация

GitHub Pages публикует статические файлы из корня ветки `main`. После включения Pages новые коммиты в `main` обновляют сайт автоматически.

## Проверка звука

```sh
node --test tests/audio.test.mjs
```

Проверяются перекрывающиеся эффекты, возврат фоновой громкости после ошибок и возобновление музыки после выключения звука. Проверка использует замену Howler без аудиоустройства.

После отсчёта воспроизводится `akto_yy_zal-nachalomeropriyatiy_[cut_10sec].mp3` вместе с началом подключения нового энергокласса; фоновая музыка остаётся приглушённой до окончания эффектов.

Карта дополнительно увеличена на 25% относительно вписанного масштаба. Боковые панели уменьшены, чтобы не закрывать контур.
